## What Went Well

1. **Code review discipline** — CR ran on all 4 code stories. Story 1-4 alone yielded 5 real patches (timezone bug, permanent-dismiss flaw, NaN bypass, setTimeout leak, keyboard accessibility gap). Every one would have shipped to production without CR.
2. **BMad workflow end-to-end** — First epic to run CS → DS → CR on every story. Process overhead paid for itself in quality.
3. **Dynamic import pattern applied consistently** — Analytics, AdMob, in-app-review, and now local-notifications all use `isNativePlatform()` guard + dynamic `import()`. No static native-plugin imports remain.
4. **Spec-first discipline** — The 4 stories with full BMad workflow were clean deliveries. Clear spec → predictable implementation.
5. **Agent caught iOS subtitle limit error** — Research doc had the subtitle at 70 characters; App Store limit is 30. Caught and resolved during story 1-1 development before submission.

---

## What Didn't Go Well

1. **Story 1-5 skipped spec and CR** — Delivered before full BMad workflow was adopted. Code was solid but undocumented. Risk was taken on luck, not process.
2. **Research documents had factual errors** — iOS subtitle character limit was wrong in the research summary. External platform constraints need verification against official docs, not just research.
3. **Deferred work items from Epic 2-3 still open** — `deferred-work.md` has two items (`Math.random()` in `$derived`, orphaned localStorage key) that have now survived two retrospectives without resolution.

---

## Key Insights

1. **Code review catches real bugs** — Story 1-4: permanent-dismiss flaw (any "Not really" tap permanently suppressed the prompt, ignoring the 365-day cooldown after reset), DST-unsafe date arithmetic in `daysSinceDate()`, missing `Number.isNaN` guards bypassing cooldown, `clearTimeout` missing from `$effect` cleanup, no keyboard accessibility in modal. All patched.
2. **Research documents are not ground truth** — External platform constraints (character limits, API quotas, store rules) must be verified against official platform docs during story creation, not trusted from research summaries.
3. **Dynamic import is now a project standard** — All native-only Capacitor plugins use `if (!Capacitor.isNativePlatform()) return; const { Plugin } = await import(...)`. Established in Epic 2-3 (analytics ad-blocker crash), now applied universally.
4. **Spec-first discipline pays off** — Stories without specs are riskier, even when the code turns out fine. The process exists for a reason.
