## What Went Well

1. **Auto-react UX** — Removing the React button and using a 180ms `$effect` timer made the core loop feel fluid and reduced tap count.
2. **CSS-only animations** — DiscoveryOverlay, DiscoveryBanner, screen-edge flash all use pure `@keyframes`. No JS animation libraries, lean bundle, 60fps on iOS.
3. **Dynamic `import()` for Firebase Analytics** — Fixed ad-blocker crash by lazy-loading `@capacitor-firebase/analytics`. Standard pattern for optional native deps going forward.
4. **SmartHint system** — `getHint()` returns trivia vs. goal mode based on remaining options — game-design-aware code.
5. **Code review caught real bugs** — Story 2-5 review found: a11y `role="button"` + `aria-live` conflict, missing `hintElResult` template guard, deterministic `getStuckHint`. All fixed before commit.
6. **Space Science pack** — 50 new elements with CVEA quality, extending game lifespan significantly.

---

## What Didn't Go Well

1. **Story 2-5 was overloaded** — Three distinct UX changes (auto-react, discovery overlay, daily pill) bundled into one story. Harder to review, larger blast radius for reverts.
2. **No architecture or PRD documents** — Research report and epics file were the only source of truth. No formal record of *why* decisions were made.
3. **Story specs missing for 6 of 9 stories** — Only 1-3, 2-5, and 3-3 had spec files. No dev notes, review findings, or completion notes for the other 6.
4. **Code review skipped for most stories** — Only 2-5 got formal review. The 6 stories without review may have latent issues.
5. **Deferred technical debt accumulating** — 2 items in `deferred-work.md`: orphaned localStorage key, impure `$derived` with `Math.random()`.

---

## Key Insights

1. High velocity was achieved but documentation was sacrificed — BMad workflow (create-story → dev-story → code-review) was followed for complex stories but skipped for simpler ones.
2. Code review catches real bugs when used — 3/3 actionable findings in the one story that was reviewed.
3. Overloaded stories increase risk — clean commits enable clean reverts.
4. CSS-only animation and dynamic import patterns are keepers.
