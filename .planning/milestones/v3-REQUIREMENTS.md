## v3 Requirements

### Platform (Capacitor)

- [x] **PLAT-01**: User's game runs as a native Android application via Capacitor _(Phase 9 — Done)_
- [x] **PLAT-02**: App can be submitted to Google Play with correct app ID, icons, splash screen, and signed release build (APK/AAB) _(Phase 9 — Done)_
- [x] **PLAT-03**: Existing web PWA build continues to function identically unchanged alongside the native build _(Phase 9 — Done)_

### Monetization — AdMob (Rewarded Ads)

- [x] **MOTZ-01**: User can watch a rewarded video ad to earn 1 free hint _(Phase 11 — Done)_
- [x] **MOTZ-04**: Ad loads asynchronously before user requests it; ad unavailable shows a friendly message without crashing _(Phase 11 — Done)_
- [ ] **MOTZ-05**: Users who purchased remove-ads never see the ad button or any ads _(Phase 12 — Pending)_

### Monetization — IAP

- [ ] **MOTZ-02**: User can purchase a one-time "remove ads" upgrade ($2.99–$4.99) that permanently hides all ads _(Phase 12 — Pending)_
- [ ] **MOTZ-03**: User can purchase a 10-hint bundle IAP _(Phase 12 — Pending)_
- [ ] **MOTZ-06**: User can restore previous purchases after reinstall or device switch _(Phase 12 — Pending)_

### Streak Bonus

- [x] **STRK-05**: Combo multiplier cap increases during active streak days (+1x per streak day, up to +3x above base 8x max) _(Phase 10 — Done)_
- [x] **STRK-06**: Active streak bonus level is visually indicated in the TopBar or BottomBar _(Phase 10 — Done)_
