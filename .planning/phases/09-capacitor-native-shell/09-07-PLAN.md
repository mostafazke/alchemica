# Plan 09-07: PLAT-03 Gate — Web Build Regression Check

## Objective

Verify that the existing web PWA build is completely unaffected by the Capacitor integration. This is the PLAT-03 hard gate: "Existing web PWA build continues to function identically unchanged alongside the native build."

All prior plans in Phase 9 must be complete before this plan runs (Wave 4). This plan makes NO file changes — it is a verification-only plan.

Purpose: Confirm that adding Capacitor, upgrading `touch.ts` haptics, and adding `android/` have not broken the web build pipeline or introduced TypeScript errors.

Output: Green test suite + confirmed web build artifacts.
