# Plan 09-09: Fix Android Custom Icon

## Goal

Replace the default Capacitor robot icon with the Alchemica icon (dark navy
background `#0D1B2E` + the 'A' foreground logo) on the Android launcher, app
drawer, and recents screen.

## Context

**Root cause (confirmed):** `@capacitor/assets generate` expects the source
file to be named `assets/icon.png`. Only `assets/icon-only.png` exists, so
the tool silently skipped foreground generation and left the Capacitor default
robot `ic_launcher_foreground.png` in place across all `mipmap-*` density
buckets. On Android 8+ (API 26+) adaptive icons are composed from
`ic_launcher_foreground.png` (the layer `@capacitor/assets` regenerates) and
`ic_launcher_background.xml` (the solid colour). Because the foreground was
never replaced the robot logo remained.

Additionally, `ic_launcher_background.xml` currently uses `#FFFFFF` (white).
The correct brand background colour is `#0D1B2E` (Alchemica navy).

**Asset that exists:** `assets/icon-only.png` — this is the correct source art.
**Asset expected by tool:** `assets/icon.png` — must be created before running generate.

**Density buckets managed by `@capacitor/assets`:**
- `mipmap-mdpi`, `mipmap-hdpi`, `mipmap-xhdpi`, `mipmap-xxhdpi`, `mipmap-xxxhdpi`

## Tasks

### Wave 0: Create `assets/icon.png`

- [ ] Copy `assets/icon-only.png` to `assets/icon.png`.
      On Windows PowerShell: `Copy-Item assets/icon-only.png assets/icon.png`
      On bash/macOS: `cp assets/icon-only.png assets/icon.png`
- [ ] Confirm `assets/icon.png` exists and is non-zero bytes before proceeding.

### Wave 1: Regenerate Android foreground PNGs

- [ ] From the project root, run:
      ```
      npx capacitor-assets generate --android
      ```
      The tool reads `assets/icon.png` and writes new `ic_launcher_foreground.png`
      files into every `android/app/src/main/res/mipmap-*/` directory.
- [ ] Confirm the files were updated — check that
      `android/app/src/main/res/mipmap-xxxhdpi/ic_launcher_foreground.png`
      has a modification timestamp newer than before the command ran.

### Wave 2: Fix the background colour

- [ ] Open `android/app/src/main/res/values/ic_launcher_background.xml`.
      Change the colour value from `#FFFFFF` (or whatever it currently is) to
      `#0D1B2E` (Alchemica navy). The file should read:
      ```xml
      <?xml version="1.0" encoding="utf-8"?>
      <resources>
          <color name="ic_launcher_background">#0D1B2E</color>
      </resources>
      ```
      Save the file.

### Wave 3: Sync and rebuild the signed AAB

- [ ] Run `npx cap sync android` to propagate web assets and any manifest
      changes into the Android project.
- [ ] From the `android/` directory, run the Gradle release bundle task:
      ```
      cd android && ./gradlew bundleRelease
      ```
      (On Windows use `gradlew.bat bundleRelease` if `./gradlew` is not executable.)
- [ ] After the build completes, return to the project root: `cd ..`

### Wave 4: Verify the rebuilt AAB

- [ ] Confirm `android/app/build/outputs/bundle/release/app-release.aab` exists
      and has a modification timestamp from this build run (not a stale artefact).
- [ ] (Human checkpoint) Install the APK variant on a device or emulator and
      verify the launcher icon shows the dark navy background with the 'A' logo.
      See UAT Criteria below.

## Verification

- [ ] `assets/icon.png` exists and is a copy of `assets/icon-only.png`.
- [ ] `android/app/src/main/res/mipmap-xxxhdpi/ic_launcher_foreground.png` is
      newer than before Wave 1 (confirm via `ls -lt` or file Explorer).
- [ ] `android/app/src/main/res/values/ic_launcher_background.xml` contains
      `#0D1B2E`.
- [ ] `android/app/build/outputs/bundle/release/app-release.aab` exists and
      was produced in the current Wave 3 build (not the prior build).
- [ ] Gradle `bundleRelease` exits with `BUILD SUCCESSFUL`.

## Threat Model

None — asset replacement and local Android build only. No network calls,
no credentials, no user data involved.

## UAT Criteria

- After installing the rebuilt APK on an Android 8+ device or emulator, navigate
  to the home screen or app drawer. The Alchemica icon must show a **dark navy
  background** (`#0D1B2E`) with the **'A' logo** as the foreground — the default
  green Capacitor robot must NOT be visible.
- The icon must look correct in both the app drawer (full icon) and the recents
  screen (small thumbnail).
