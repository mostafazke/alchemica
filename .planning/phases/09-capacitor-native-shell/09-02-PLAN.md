# Plan 09-02: Capacitor 8 Foundation — Packages, Config, Scripts, Gitignore

## Objective

Install Capacitor 8 packages, create `capacitor.config.ts` with correct app identity (D-01–D-03, D-10), add `cap:*` npm scripts (D-11), and update `.gitignore` with Android secrets entries (D-07). This plan is Wave 1 and has no dependencies — it provides the foundation for all subsequent plans.

**Critical:** Install `@capacitor/*@latest` (= v8.3.1) NOT v6. Capacitor 6 requires Android SDK platform android-34 which is not installed. The environment has android-36 which matches Capacitor 8's compileSdk 36.

Purpose: Make Capacitor 8 available as a dev/prod dependency and establish the project identity that will be used throughout the native build pipeline.

Output: Installed packages, `capacitor.config.ts`, updated `package.json` scripts, updated `.gitignore`.

<action>
Create `capacitor.config.ts` at the project root with this exact content:

```typescript
import type { CapacitorConfig } from '@capacitor/cli';

// D-01: appId locked for Play Store registration — do NOT change
// D-02, D-03: appName matches PWA short_name
// D-10: webDir must be 'build' — SvelteKit adapter-static outputs to build/, not dist/
const config: CapacitorConfig = {
  appId: 'io.alchemica.app',
  appName: 'Alchemica',
  webDir: 'build',

  plugins: {
    SplashScreen: {
      launchShowDuration: 2000,
      launchAutoHide: true,
      backgroundColor: '#0d1b2e',  // matches vite.config.ts theme_color
      androidScaleType: 'CENTER_CROP',
    },
    StatusBar: {
      style: 'DARK',
      backgroundColor: '#0d1b2e',  // matches vite.config.ts background_color
      overlaysWebView: false,
    },
  },
};

export default config;
```

IMPORTANT — Orientation (D-05 correction): There is NO `screenOrientation` key in `CapacitorConfig`. Do NOT add it here. Orientation is set in `android/app/src/main/AndroidManifest.xml` in Plan 09-04. If a `screenOrientation` key is added here, it is silently ignored and provides false confidence.

IMPORTANT — No androidScheme: Do NOT add `server: { androidScheme: 'http' }`. This is a greenfield install; use the default `https` scheme (Pitfall 1 from RESEARCH.md).
</action>

Windows note on `cap:build`: The `&&` chaining works when npm runs via Git Bash (standard on Windows). If running in pure PowerShell, `./gradlew` must be `gradlew.bat`. Document this in code as a comment if needed, but do NOT change the script value.
