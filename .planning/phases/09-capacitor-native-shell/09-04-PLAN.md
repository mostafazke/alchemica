# Plan 09-04: Android Platform — npx cap add android + Orientation Lock + JDK Config

## Objective

Add the Android platform to the Capacitor project (`npx cap add android`), lock screen orientation to landscape in `AndroidManifest.xml` (D-05 corrected), and configure Gradle to use Android Studio's bundled JDK 21 instead of system Java 17.

This plan depends on Plan 09-02 (Capacitor packages must be installed before `npx cap add android`).

Purpose: Create the `android/` Gradle project that serves as the native container. Without this, Plans 09-05 and 09-06 cannot proceed.

Output: `android/` directory committed (minus secrets), orientation locked, Gradle JDK configured.

<action>
**Part A: AndroidManifest.xml — Orientation Lock**

Read the generated `android/app/src/main/AndroidManifest.xml`. Find the `<activity>` element (it will have `android:name=".MainActivity"` or `android:name="io.alchemica.app.MainActivity"`).

Add `android:screenOrientation="sensorLandscape"` to this activity element.

Also ensure `android:configChanges` includes `density` as required by Capacitor 8 (if `configChanges` is already present, add `|density` to the end of the value; if not present, add the full attribute).

The activity element after modification must have these attributes (other existing attributes must be preserved):
```xml
<activity
  android:name=".MainActivity"
  android:exported="true"
  android:screenOrientation="sensorLandscape"
  android:configChanges="orientation|keyboardHidden|keyboard|screenSize|locale|smallestScreenSize|screenLayout|uiMode|density"
  android:label="@string/app_name"
  android:theme="@style/AppTheme.NoActionBarLaunch">
```

Note: The exact set of existing attributes may differ from the example above. Only ADD `screenOrientation` and ensure `density` is in `configChanges`. Do NOT remove any existing attributes.

`sensorLandscape` (not `landscape`) is correct: allows landscape-left and landscape-right based on physical sensor, matching the PWA manifest `"orientation": "landscape"` in vite.config.ts.

**Part B: android/gradle.properties — JDK 21 Configuration**

Read `android/gradle.properties`. Add the following line at the end of the file:

```properties
# Use Android Studio's bundled JBR 21 instead of system Java 17
# This ensures Gradle uses JDK 21 for Cap 8 builds
org.gradle.java.home=C:/Program Files/Android/Android Studio/jbr
```

IMPORTANT: Use forward slashes (`C:/Program Files/...`), not backslashes, in Gradle properties files. Gradle reads this on Windows correctly with forward slashes.

This path is correct for Android Studio 2025.3.1 (AI-253) as verified in RESEARCH.md environment inventory.

After both edits, run a Gradle task to verify the project builds:
```bash
cd android && ./gradlew tasks --quiet 2>&1 | head -20
```

On Windows, if `./gradlew` fails, use `./gradlew.bat tasks --quiet`.
</action>

   - App is in landscape orientation — rotating the device keeps it in landscape
   - Basic game interaction works (tap elements, try a reaction)

If the app shows a blank screen: the most common cause is `webDir: 'dist'` instead of `'build'` in capacitor.config.ts. Verify `grep "webDir" capacitor.config.ts` shows `build`.

If orientation is wrong: verify `grep "sensorLandscape" android/app/src/main/AndroidManifest.xml` returns a match.
