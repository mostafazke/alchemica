# Plan 09-05: Icons and Splash Screen — @capacitor/assets Generate

## Objective

Create a 1024×1024 source icon (`assets/icon-only.png`) and run `npx capacitor-assets generate --android` to produce all required Android launcher icon densities and splash screen drawables. This satisfies the Google Play icon and splash requirements for PLAT-02.

This plan depends on Plan 09-04 (`android/` directory must exist before assets can be written to it).

Purpose: The existing `static/icon-512.png` is too small (512px vs 1024px minimum required by `@capacitor/assets`). A new source file at 1024×1024 must be created before generation.

Output: `assets/icon-only.png` (source, committed), all `android/app/src/main/res/mipmap-*/` icon files, all `android/app/src/main/res/drawable/` splash files.

## Tasks

<task id="9-05-01" type="auto">
<title>Task 1: Create assets/icon-only.png at 1024x1024</title>
<read_first>
- .planning/phases/09-capacitor-native-shell/09-RESEARCH.md lines 376–399 (icon source requirements — 1024x1024 minimum, @capacitor/assets directory structure)
- static/icon-512.png (visual reference — use this as the design source but it must be scaled up to 1024x1024)
</read_first>
<action>
Create the `assets/` directory at project root and create `assets/icon-only.png` at 1024×1024 pixels.

**Method A — If ImageMagick is available:**
```bash
# Scale up existing 512px icon to 1024px
magick static/icon-512.png -resize 1024x1024 assets/icon-only.png
```

**Method B — If Node/Canvas is available:**
Use a Node script to create a simple 1024×1024 icon with the Alchemica color scheme:
```bash
node -e "
const { createCanvas } = require('canvas');
const fs = require('fs');
const canvas = createCanvas(1024, 1024);
const ctx = canvas.getContext('2d');
// Background matching game theme
ctx.fillStyle = '#0d1b2e';
ctx.fillRect(0, 0, 1024, 1024);
// Simple 'A' text centered
ctx.fillStyle = '#4fc3f7';
ctx.font = 'bold 600px sans-serif';
ctx.textAlign = 'center';
ctx.textBaseline = 'middle';
ctx.fillText('A', 512, 512);
fs.writeFileSync('assets/icon-only.png', canvas.toBuffer('image/png'));
"
```

**Method C — Manual (preferred if A and B are not available):**
1. Create `assets/` directory: `mkdir assets`
2. Open `static/icon-512.png` in any image editor (Paint.NET, GIMP, Photoshop, or even MS Paint)
3. Scale the image to 1024×1024 pixels (use nearest-neighbor or bilinear scaling)
4. Save as `assets/icon-only.png`
5. If no image editor is available: copy `static/icon-512.png` to `assets/icon-only.png` as a temporary placeholder — `@capacitor/assets` will accept it but warn about size; the warning is acceptable and icons will still be generated

**Method D — Simplest fallback (PowerShell, no tools required):**
```powershell
# Create assets directory
New-Item -ItemType Directory -Path assets -Force

# Copy icon-512 as placeholder (will generate warnings from capacitor-assets but works)
Copy-Item static/icon-512.png assets/icon-only.png
```

Use whatever method is available. A proper 1024×1024 icon is ideal but the 512px placeholder will work for generating testable icons.

After creating the file, verify it is a valid PNG:
```bash
file assets/icon-only.png
# Expected: PNG image data, ... x ... (size may vary)
```
</action>
<acceptance_criteria>
- `assets/icon-only.png` file exists
- File is a valid PNG (not zero bytes): `wc -c assets/icon-only.png` returns > 1000 bytes
- `mkdir -p assets` (assets/ directory exists)
</acceptance_criteria>
</task>

<task id="9-05-02" type="auto">
<title>Task 2: Generate Android icons and splash drawables with @capacitor/assets</title>
<read_first>
- assets/icon-only.png (must exist from Task 1 before running this)
- android/app/src/main/res/ (verify structure exists — android/ must be from Plan 09-04)
- .planning/phases/09-capacitor-native-shell/09-RESEARCH.md lines 377–399 (generation command and output locations)
</read_first>
<action>
Run `@capacitor/assets` to generate all Android icon and splash drawable variants:

```bash
npx capacitor-assets generate --android
```

This command reads `assets/icon-only.png` and generates:
- `android/app/src/main/res/mipmap-mdpi/ic_launcher.png` (48×48)
- `android/app/src/main/res/mipmap-hdpi/ic_launcher.png` (72×72)
- `android/app/src/main/res/mipmap-xhdpi/ic_launcher.png` (96×96)
- `android/app/src/main/res/mipmap-xxhdpi/ic_launcher.png` (144×144)
- `android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png` (192×192)
- `android/app/src/main/res/mipmap-*/ic_launcher_foreground.png` (adaptive icon foreground)
- `android/app/src/main/res/drawable/splash.png` (splash screen)
- And other density/format variants

If the command produces warnings about image size (e.g., "source image is smaller than recommended 1024px"), these are acceptable. The command will still succeed and generate all required files.

If the command fails with "assets/icon-only.png not found": verify Task 1 completed and the file exists at `assets/icon-only.png` (not `assets/icons/icon-only.png`).

After generation, do a quick sync so the icons are reflected in the APK build:
```bash
npx cap sync
```
</action>
<acceptance_criteria>
- `android/app/src/main/res/mipmap-hdpi/ic_launcher.png` exists
- `android/app/src/main/res/mipmap-mdpi/ic_launcher.png` exists
- `android/app/src/main/res/mipmap-xhdpi/ic_launcher.png` exists
- `android/app/src/main/res/mipmap-xxhdpi/ic_launcher.png` exists
- `android/app/src/main/res/mipmap-xxxhdpi/ic_launcher.png` exists
- All listed files are > 500 bytes (not zero-byte placeholders)
- `npx cap sync` exits 0 after generation
</acceptance_criteria>
</task>
