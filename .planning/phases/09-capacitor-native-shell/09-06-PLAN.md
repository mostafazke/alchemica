# Plan 09-06: Keystore Generation, Gradle Signing Config, and Signed AAB Build

## Objective

Generate the release signing keystore, configure Gradle to load signing credentials from `android/local.properties` (gitignored), and produce a signed release AAB. This satisfies PLAT-02 (Google Play-ready signed release build) and D-06/D-07 (keystore stored locally, never committed).

This plan depends on Plan 09-04 (`android/app/build.gradle` must exist before it can be modified).

Purpose: A signed AAB is required for Google Play submission. The keystore must be generated once and kept secure — never committed to git.

Output: Release keystore, Gradle signing config, signed `app-release.aab`.

<action>
This task requires a manual step by the developer because the keystore contains private key material.

**BEFORE running keytool: verify .gitignore protection**
```bash
grep "android/\*.jks" .gitignore
```
This must return a match. If not, add `android/*.jks` to .gitignore NOW before creating the keystore.

**Generate the keystore:**
Run this command from the project root (not from android/):

```bash
keytool -genkey -v \
  -keystore android/alchemica-release-key.jks \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10950 \
  -alias alchemica-key
```

On Windows PowerShell, use backtick for line continuation:
```powershell
keytool -genkey -v `
  -keystore android/alchemica-release-key.jks `
  -keyalg RSA `
  -keysize 2048 `
  -validity 10950 `
  -alias alchemica-key
```

`keytool` is part of the JDK (system Java 17 or Android Studio JBR 21 — either works for key generation).

**When prompted, enter:**
- `Enter keystore password:` — choose a strong password and RECORD IT SECURELY
- `Re-enter new password:` — same password
- `What is your first and last name?` — your name or organization name
- `What is the name of your organizational unit?` — can leave blank (press Enter)
- `What is the name of your organization?` — your organization or name
- `What is the name of your City or Locality?` — your city
- `What is the name of your State or Province?` — your state/province
- `What is the two-letter country code for this unit?` — e.g., `EG` for Egypt
- `Is CN=..., OU=..., O=..., L=..., ST=..., C=... correct?` — type `yes`
- `Enter key password for <alchemica-key>:` — press Enter to use the same password as keystore, OR choose a different password and record it

**CRITICAL:** Store the keystore password(s) in a password manager or secure note NOW. If you lose the keystore password, you cannot update your Play Store app with the same signing key — you would need to create a new app listing.

**Verify keystore was created:**
```bash
ls -la android/alchemica-release-key.jks
# Expected: file exists, > 1KB
```

**Verify it is NOT tracked by git:**
```bash
git status android/alchemica-release-key.jks
# Expected: shows as untracked (not staged, not committed)
```
</action>

<task id="9-06-03" type="auto">
<title>Task 3: Add Gradle signing config to android/app/build.gradle and build signed AAB</title>
<read_first>

- .planning/phases/09-capacitor-native-shell/09-RESEARCH.md lines 333–372 (exact Gradle signing config with localProps loader)

<action>
Read the current `android/app/build.gradle`. It is a Groovy file generated by Capacitor.

**Step 1: Add localProps loader at the top of the file**

Add these lines after any existing `apply plugin:` declarations but BEFORE the `android {` block:

```groovy
// Load release signing credentials from local.properties (gitignored — never hardcode passwords)
def localProps = new Properties()
def localPropsFile = rootProject.file('local.properties')
if (localPropsFile.exists()) {
    localPropsFile.withInputStream { localProps.load(it) }
}
```

**Step 2: Add signingConfigs block inside android { }**

Inside the `android { }` block, ADD a `signingConfigs` block. Place it BEFORE the existing `buildTypes` block:

```groovy
    signingConfigs {
        release {
            storeFile     file(localProps['RELEASE_KEYSTORE_PATH'] ?: '')
            storePassword localProps['RELEASE_KEYSTORE_PASSWORD'] ?: ''
            keyAlias      localProps['RELEASE_KEY_ALIAS']          ?: ''
            keyPassword   localProps['RELEASE_KEY_PASSWORD']       ?: ''
        }
    }
```

**Step 3: Update buildTypes.release to use signingConfig**

Find the existing `buildTypes { release { ... } }` block. Add or replace the `signingConfig` line:

```groovy
    buildTypes {
        release {
            signingConfig    signingConfigs.release
            minifyEnabled    false
            proguardFiles    getDefaultProguardFile('proguard-android.txt'), 'proguard-rules.pro'
        }
    }
```

If `minifyEnabled` or `proguardFiles` lines already exist, keep them. Only add `signingConfig signingConfigs.release` — do not remove existing lines.

**Step 4: Build the signed AAB**

```bash
cd android && ./gradlew bundleRelease
```

On Windows, if `./gradlew` fails in Git Bash, try:
```powershell
cd android; .\gradlew.bat bundleRelease
```

The build may take 2–5 minutes on first run (downloads Gradle wrapper and compiles).

Expected output path: `android/app/build/outputs/bundle/release/app-release.aab`

If the build fails with "Keystore file 'alchemica-release-key.jks' not found":
- Verify `android/alchemica-release-key.jks` exists (Task 1)
- The `RELEASE_KEYSTORE_PATH` in local.properties uses a RELATIVE path from `android/app/` — if the .jks is at `android/alchemica-release-key.jks`, the relative path from `android/app/` is `../alchemica-release-key.jks`. Fix by changing `RELEASE_KEYSTORE_PATH=alchemica-release-key.jks` to `RELEASE_KEYSTORE_PATH=../alchemica-release-key.jks` in local.properties.

Actually: the `file()` call in Gradle resolves relative to the `android/app/` directory (the module directory). If the .jks is at `android/alchemica-release-key.jks`, set `RELEASE_KEYSTORE_PATH=../alchemica-release-key.jks` in local.properties. Adjust if you placed the .jks elsewhere.
</action>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| android/local.properties → git | Secrets must not cross this boundary; .gitignore is the gate |
| Gradle build process → AAB output | Signing happens inside Gradle; private key never leaves local.properties |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-06-01 | Information Disclosure | Keystore password in local.properties | mitigate | `android/local.properties` gitignored (Plan 09-02); `git status android/local.properties` must show untracked in acceptance criteria |
| T-09-06-02 | Information Disclosure | Keystore .jks file committed | mitigate | `android/*.jks` gitignored (Plan 09-02); verified in acceptance criteria with `git status` |
| T-09-06-03 | Tampering | android:debuggable in release build | accept | Capacitor's generated `buildTypes.release` does not set `debuggable true`; default is false; do not add it |
| T-09-06-04 | Repudiation | Unsigned AAB submitted to Play Store | mitigate | Signing config required before `./gradlew bundleRelease`; Play Store rejects unsigned AAB at upload time |
| T-09-06-05 | Information Disclosure | Hardcoded password in build.gradle | mitigate | `localProps['RELEASE_KEYSTORE_PASSWORD']` pattern loads from gitignored file; acceptance criteria grep verifies no plaintext password |
</threat_model>
