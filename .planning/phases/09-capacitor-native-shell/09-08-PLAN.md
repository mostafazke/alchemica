# Plan 09-08: Fix Mobile Shelf Scrollability

## Goal

Make the element shelf/sidebar scrollable on mobile (≤768px) so every unlocked element
is reachable by scrolling, with no elements cut off below the fold.

## Context

**Root cause (confirmed):** The `.shelf-container` in `+page.svelte` uses
`position: fixed` with `top` and `bottom` anchors on mobile, but lacks
`display: flex; flex-direction: column` to propagate that constrained height
down into its child. As a result `.shelf-panel` in `Shelf.svelte` has no
explicit height budget to work against, so `flex: 1; overflow-y: auto` on
`.elements-list` never activates because there is no bounded parent.
Additionally, `min-height: 0` is missing on the flex chain (a required
companion for `flex: 1` to clip content) and iOS needs
`-webkit-overflow-scrolling: touch` for momentum scroll.

**Current CSS (from `+page.svelte` mobile media query, lines ~96–120):**
```css
@media (max-width: 768px) {
  .shelf-container {
    position: fixed;
    top: calc(52px + env(safe-area-inset-top, 0px));
    left: 0;
    bottom: calc(56px + env(safe-area-inset-bottom, 0px));
    width: 260px;
    z-index: 200;
    transform: translateX(-100%);
    transition: transform 0.25s ease;
    overflow: hidden;      /* ← clips children, no flex propagation */
  }
}
```

**Current CSS (from `Shelf.svelte`, lines ~117–143):**
```css
.shelf-panel {
  display: flex; flex-direction: column;
  overflow: hidden;        /* ← correct, but no height constraint from parent */
}
.elements-list {
  flex: 1; overflow-y: auto;  /* ← never scrolls without min-height: 0 on chain */
}
```

### Wave 0: Read and confirm current CSS structure

- [ ] Read `src/routes/+page.svelte` mobile media query (lines 90–120) to confirm
      `.shelf-container` lacks `display: flex`.
- [ ] Read `src/lib/components/Shelf.svelte` styles (lines 117–160) to confirm
      `.shelf-panel` and `.elements-list` are present as described above.

### Wave 1: Fix `+page.svelte` — add flex to `.shelf-container` mobile query

- [ ] In `src/routes/+page.svelte`, inside the `@media (max-width: 768px)` block,
      add `display: flex; flex-direction: column;` to `.shelf-container` so the
      fixed-height container propagates its bounded height to children.
      The rule should read:
      ```css
      .shelf-container {
        position: fixed;
        top: calc(52px + env(safe-area-inset-top, 0px));
        left: 0;
        bottom: calc(56px + env(safe-area-inset-bottom, 0px));
        width: 260px;
        z-index: 200;
        transform: translateX(-100%);
        transition: transform 0.25s ease;
        overflow: hidden;
        display: flex;
        flex-direction: column;
      }
      ```

### Wave 2: Fix `Shelf.svelte` — add `min-height: 0` to scroll chain

- [ ] In `src/lib/components/Shelf.svelte`, add `flex: 1; min-height: 0;` to
      the `.shelf-panel` rule (it already has `display: flex; flex-direction: column`
      and `overflow: hidden` — this makes it fill the parent flex container and
      establishes a bounded height for its children):
      ```css
      .shelf-panel {
        display: flex; flex-direction: column;
        background: #080f1a;
        border-right: 1px solid #1a2e4a;
        width: 100%; flex-shrink: 0;
        overflow: hidden;
        flex: 1;
        min-height: 0;
      }
      ```
- [ ] In `src/lib/components/Shelf.svelte`, add `min-height: 0;` and
      `-webkit-overflow-scrolling: touch;` to `.elements-list` so the iOS
      momentum scroll works and the flex child cannot overflow its container:
      ```css
      .elements-list {
        flex: 1; overflow-y: auto;
        padding: 2px 8px 8px;
        display: flex; flex-direction: column; gap: 3px;
        min-height: 0;
        -webkit-overflow-scrolling: touch;
      }
      ```
