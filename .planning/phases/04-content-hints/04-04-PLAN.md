# Plan 04-04: HintButton.svelte component

## Goal
Build HintButton with countdown display, disable state, and hint overlay.

## Tasks

### Task 1 — Create `src/lib/components/HintButton.svelte`
- Reads `unlockedElements` and `hintCooldownEndsAt` stores
- `$derived` `cooldownRemaining`: `Math.max(0, Math.ceil(($hintCooldownEndsAt - now) / 1000))`
- `$derived` `hint`: calls `getHint($unlockedElements)` — null if nothing available
- `$derived` `canHint`: `cooldownRemaining === 0 && hint !== null`
- `let now = $state(Date.now())` — updated by `setInterval(1000)` inside `$effect`
- On click: sets `hintCooldownEndsAt.set(Date.now() + 30_000)`, shows `hintResult` overlay
- Overlay shows: "Try: [A symbol] [A name] + [B symbol] [B name]"
- Button shows: "Hint" | "⏱ {N}s" | "No hints" depending on state

### Task 2 — Wire HintButton into MixingChamber.svelte
- Import and render `<HintButton />` below the React button
