### Task 2 — Add `getHint()` to `lib/game/reactions.ts`
```ts
export function getHint(unlocked: Set<string>): { a: string; b: string; result: string } | null
```
- Iterates REACTIONS; for each pair `[a, b]` → `result`:
  - Skip if `unlocked.has(result)` (already known)
  - Skip if `!unlocked.has(a) || !unlocked.has(b)` (can't make)
  - Return first valid `{ a, b, result }` found
- Avoid duplicate reverse-pair iterations (skip if `a > b` when both orderings present)
