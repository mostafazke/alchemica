# Plan 04-05: Share utility + wire to DiscoveryItem + ResultDisplay

## Goal
Build Web Share API utility with clipboard fallback; add share button to DiscoveryItem and ResultDisplay.

## Tasks

### Task 1 — Create `src/lib/utils/share.ts`
```ts
export async function shareDiscovery(elementKey: string): Promise<{ ok: boolean; method: 'share' | 'clipboard' | 'none' }>
```
- Builds share text: `"I discovered ${name} (${formula}) in Alchemica! 🧪 ${window.location.href}"`
- If `navigator.share` available: calls it, returns `{ ok: true, method: 'share' }`
- Else if `navigator.clipboard`: copies text, returns `{ ok: true, method: 'clipboard' }`
- Else returns `{ ok: false, method: 'none' }`

### Task 2 — Add share button to `DiscoveryItem.svelte`
- Add small 🔗 icon button after disc-info
- On click: calls `shareDiscovery(discovery.key)`
- Show brief "Copied!" feedback (1.5s) on clipboard method

### Task 3 — Add share button to `ResultDisplay.svelte`
- On successful new discovery (`isNew === true`): show "Share" button below result
- Calls `shareDiscovery(result)`

## Verification
- `npm run check` passes
- Share button visible in DiscoveryItem and ResultDisplay new-discovery state
- `npm run build` succeeds
