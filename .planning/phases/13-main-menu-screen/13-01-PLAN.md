# Plan 13-01: Route Restructure + Menu Component

## Goal
Move the existing game to `/game` and replace the root route with a branded main menu screen.

## Context
Currently `src/routes/+page.svelte` is the full game. This plan moves it to `src/routes/game/+page.svelte` (no code changes, file move only) and creates a new `src/routes/+page.svelte` menu with title + Play button. The root `+layout.ts` exports `prerender = true` and `ssr = false` which cascade to `/game` automatically — no `game/+page.ts` is needed.

## Tasks

### Task 1: Move game to `/game` route
**File:** `src/routes/game/+page.svelte`
**Action:** create (by copying the full contents of the current `src/routes/+page.svelte`)
**Details:**
Create `src/routes/game/+page.svelte` with the exact same content as the current `src/routes/+page.svelte`. Do not modify any logic, imports, or markup. The file is:
