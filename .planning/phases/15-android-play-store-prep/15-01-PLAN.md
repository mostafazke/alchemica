<task type="auto">
  <name>Task 1: Replace hardcoded RC API key placeholder with env-variable pattern</name>
  <files>src/lib/effects/iap.ts, .env.local.example</files>
  <action>
In `src/lib/effects/iap.ts`, replace the single line:

    const RC_API_KEY = 'goog_REPLACE_ME';

with:

    // Set VITE_RC_API_KEY in .env.local (gitignored) before building for Play Store.
    // Obtain from: https://app.revenuecat.com → Project Settings → Android app → API keys
    // The value starts with 'goog_' for Android projects.
    // IMPORTANT: .env.local is gitignored — never paste the real key into this source file.
    const RC_API_KEY = import.meta.env.VITE_RC_API_KEY ?? '';

The `import.meta.env.VITE_RC_API_KEY` is resolved by Vite at build time, so the real key
is embedded in the compiled bundle (standard practice for RC public keys) but never
committed to git. An empty fallback means the SDK init throws on native, which is caught
by the existing try/catch in initIAP() — safe behaviour.

Also create `.env.local.example` at the repo root with this content (safe to commit):

    # Copy this file to .env.local and fill in your real values.
    # .env.local is gitignored — never commit the real keys.

    # RevenueCat Android API key (starts with 'goog_')
    # Obtain from: https://app.revenuecat.com → Project Settings → Android app → API keys
    VITE_RC_API_KEY=goog_REPLACE_WITH_YOUR_KEY

Do NOT modify any other logic in iap.ts.
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .env.local → Vite build | VITE_RC_API_KEY is embedded in the compiled JS bundle at build time |
| Android app → RC API | RC public API key is a client-side identifier; not a secret |
| Play Console credentials | Held by the developer — not stored in source |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-01 | Information Disclosure | RC_API_KEY in source control | mitigate | Use `import.meta.env.VITE_RC_API_KEY` — .env.local is gitignored; .env.local.example has no real key |
| T-15-02 | Information Disclosure | Signing keystore credentials | accept | Already mitigated in Phase 9 — local.properties is gitignored; signing config reads from it |
| T-15-03 | Tampering | Purchase receipt spoofing | accept | RC server-side receipt validation is the standard mitigation; client-side only is acceptable for this scale |
| T-15-04 | Elevation of Privilege | RC entitlement grant without purchase | accept | RC enforces purchase validation server-side; no client code can self-grant entitlements |
</threat_model>
