  <name>Task 1: Create ElementGrid.svelte — scrollable grid with filter tabs</name>
  <files>src/lib/components/ElementGrid.svelte</files>
  <action>
Create `src/lib/components/ElementGrid.svelte` that replaces `Shelf.svelte` (per D-03). Port the filter logic and element listing from Shelf but display as a responsive CSS grid instead of a vertical list.

**Structure:**
- Filter tabs row at top: All / Basic / Found (sticky, same logic as Shelf.svelte)
- Below: scrollable CSS grid of ElementCard components
- Grid uses `display: grid; grid-template-columns: repeat(auto-fill, minmax(72px, 1fr)); gap: 6px`
- No category grouping — flat grid in all filter modes (categories were only useful in the narrow sidebar; grid is already visually scannable by icon)
- Import `unlockedElements` from stores, `ELEMENTS` from data, `ElementCard` from components
- Pass `mode="grid"` prop to ElementCard so it renders in compact tile mode

**Filter logic (port from Shelf.svelte):**
```typescript
let filter: 'all' | 'basic' | 'found' = $state('all');
const filteredKeys = $derived(
  [...$unlockedElements].filter((k) => {
    if (filter === 'basic') return ELEMENTS[k]?.category === 'basic';
    if (filter === 'found') return ELEMENTS[k]?.category !== 'basic';
    return true;
  })
);
```

**Template structure:**
```html
<div class="element-grid-panel">
  <div class="grid-tabs">
    <button class="tab-btn" class:active={filter === 'all'} ...>All</button>
    <button class="tab-btn" class:active={filter === 'basic'} ...>Basic</button>
    <button class="tab-btn" class:active={filter === 'found'} ...>Found</button>
  </div>
  <div class="grid-scroll">
    {#each filteredKeys as key (key)}
      <ElementCard elementKey={key} mode="grid" />
    {:else}
      <p class="empty-grid">No elements yet</p>
    {/each}
  </div>
</div>
```

**Styles (scoped):**
- `.element-grid-panel`: `display: flex; flex-direction: column; height: 100%; overflow: hidden; background: #080f1a; border-right: 1px solid #1a2e4a;`
- `.grid-tabs`: `display: flex; gap: 4px; padding: 8px 10px; flex-shrink: 0;` (sticky at top)
- `.tab-btn`: Same styling as Shelf tabs with 36px min-height touch targets
- `.grid-scroll`: `flex: 1; overflow-y: auto; padding: 8px 10px; display: grid; grid-template-columns: repeat(auto-fill, minmax(72px, 1fr)); gap: 6px; align-content: start; -webkit-overflow-scrolling: touch;`
- No portrait media queries — landscape only
