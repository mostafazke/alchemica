# Plan 05-01: Finalize vite-plugin-pwa configuration

## Goal
Ensure the VitePWA plugin is fully configured with the correct Workbox GenerateSW strategy,
proper caching rules for all asset types, and `injectRegister: 'auto'` so the service worker
auto-registers without manual JS.

## Tasks

### Task 1 — Audit current vite.config.ts PWA block
Read `vite.config.ts` and verify:
- `registerType: 'autoUpdate'` is set
- `injectRegister: 'auto'` is set (add if missing)
- `workbox.globPatterns` covers `**/*.{js,css,html,ico,png,svg,woff2}`
- `devOptions.enabled: true` is set for dev-mode SW testing (optional but useful)

### Task 2 — Fix vite.config.ts PWA block
Apply any missing fields identified in Task 1.

### Task 3 — Verify build output
Run `npm run build` and confirm:
- `build/sw.js` exists
- `build/manifest.webmanifest` exists
- `build/registerSW.js` exists
- No build errors
