# Plan 05-02: Create PWA icons

## Goal
Generate 192×192 and 512×512 PNG icons for the PWA manifest.
The icons use the Alchemica brand identity: dark navy background (#0d1b2e),
flask/atom symbol in accent gold (#e8b84b).

## Tasks

### Task 1 — Create icon generation script
Write a Node.js script (`scripts/gen-icons.js`) that uses the `canvas` npm package (built-in
in modern Node via `@napi-rs/canvas` or falls back to SVG approach) OR simply encodes
a minimal valid PNG using raw bytes for each size.

**Fallback approach (no external deps):** Use a pre-encoded base64 minimal PNG placeholder
that can be decoded and written to disk with Node.js `Buffer.from(base64, 'base64')`.

### Task 2 — Generate icons
Run the script and place output at:
- `static/icon-192.png`
- `static/icon-512.png`

### Task 3 — Verify icons load
Rebuild with `npm run build` and verify the icons are copied to `build/icon-192.png` and
`build/icon-512.png`.
