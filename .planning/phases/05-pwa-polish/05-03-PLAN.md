# Plan 05-03: Build OfflineIndicator.svelte

## Goal
Build a toast component that listens to `navigator.onLine` events and shows a subtle
offline/online notification when the network status changes.

## Tasks

### Task 1 — Create `src/lib/components/OfflineIndicator.svelte`
- Subscribe to `window` `online` / `offline` events in `$effect`
- Use `$state(navigator.onLine)` to track status
- Show a fixed-position toast at the bottom-center when offline: "⚡ Playing offline"
- Show a brief "✓ Back online" toast for 2s when reconnected, then hide
- CSS: dark semi-transparent background, rounded pill, z-index above all content

### Task 2 — Wire into `src/routes/+layout.svelte`
Import and render `<OfflineIndicator />` in the layout (renders on all pages).

### Task 3 — Verify with `npm run check`
Run svelte-check; fix any TypeScript errors.
