# Plan 05-04: CDN audit and apple-touch-icon

## Goal
Verify the production build has zero CDN dependencies. Add Apple touch icon
link tag for iOS homescreen install quality.

## Tasks

### Task 1 — CDN audit
Run: `grep -r "cdn\|googleapis\|gstatic\|cdnjs\|unpkg\|jsdelivr" build/ 2>/dev/null`
Expect 0 matches. Document result.

### Task 2 — Add apple-touch-icon link to app.html
In `src/app.html`, add inside `<head>`:
```html
<link rel="apple-touch-icon" href="/icon-192.png" />
```
This enables iOS "Add to Home Screen" to use the correct icon.

### Task 3 — Add manifest link fallback to app.html
Verify that `%sveltekit.head%` already injects the manifest link (it does via vite-plugin-pwa).
If not, add `<link rel="manifest" href="/manifest.webmanifest" />` explicitly.

### Task 4 — Final build + verify
Run `npm run build` → confirm 0 errors, all PWA files present.
