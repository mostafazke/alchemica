# Plan 11-02 — hintBalance Store

## Goal
Add `hintBalance: writable<number>(0)` to `src/lib/stores/game.ts`, persisted
via a standalone localStorage key (same pattern as `hintCooldownEndsAt`).
Phase 12 will promote this into the main versioned save blob.

## Tasks

### Task 1: Add store to `src/lib/stores/game.ts`

Add after the `hintCooldownEndsAt` declaration block:

```ts
/** Earned hint credits from rewarded ads. Decremented when used, never touches cooldown. */
export const hintBalance = writable<number>(
  typeof localStorage !== 'undefined'
    ? Number(localStorage.getItem('alchemica_hint_balance') ?? 0)
    : 0
);
```

Add persistence subscriber at the end of the subscribers block:

```ts
hintBalance.subscribe((v) => {
  try { localStorage.setItem('alchemica_hint_balance', String(v)); } catch { /* ignore */ }
});
```

### Task 2: Clear on resetGame
Add `hintBalance.set(0);` inside `resetGame()` (alongside the other store resets).
Also remove the localStorage key:
```ts
localStorage.removeItem('alchemica_hint_balance');
```

## Verification
- `hintBalance` exported from `game.ts`
- Initializes from `localStorage.getItem('alchemica_hint_balance')`
- Subscribes to write back on change
- `resetGame()` clears both store and localStorage key
