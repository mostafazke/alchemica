# Plan 11-01 — AdMob Plugin Install + Android Config

## Goal
Install `@capacitor-community/admob`, configure test IDs in AndroidManifest.xml and
capacitor.config.ts, run cap sync.

## Context
- Capacitor version: `^8.3.1`
- Test App ID: `ca-app-pub-3940256099942544~3347511713`
- Test Rewarded Unit ID: `ca-app-pub-3940256099942544/5224354917`

## Tasks

### Task 1: Install plugin
```bash
npm install @capacitor-community/admob
```
Expected: package added to `dependencies` in `package.json`.

### Task 2: Update `android/app/src/main/AndroidManifest.xml`
Add Google Ads Application ID meta-data **inside `<application>` before the closing tag**:
```xml
<meta-data
    android:name="com.google.android.gms.ads.APPLICATION_ID"
    android:value="ca-app-pub-3940256099942544~3347511713"/>
```

### Task 3: Update `capacitor.config.ts`
Add AdMob plugin config block to the `plugins` object:
```ts
AdMob: {
  appIdAndroid: 'ca-app-pub-3940256099942544~3347511713',
  isTesting: true,
},
```
**Note for production:** User must create an AdMob account at admob.google.com, create
an app entry and a rewarded ad unit, then replace both test IDs with real ones.

### Task 4: Sync native project
```bash
npx cap sync android
```
Expected: exits 0 with "✔ Sync finished".

## Verification
- `android/app/src/main/AndroidManifest.xml` contains `com.google.android.gms.ads.APPLICATION_ID`
- `capacitor.config.ts` has `AdMob.appIdAndroid` key
- `npx cap sync android` exits 0
