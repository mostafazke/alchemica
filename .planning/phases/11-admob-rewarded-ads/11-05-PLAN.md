# Plan 11-05 — Verification Gate

## Goal
Confirm the full Phase 11 implementation is type-safe, builds to production, and
the Android native project is in sync with the updated web bundle.

## Tasks

### Task 1: Type check
```bash
npm run check
```
Expected: 0 errors.

### Task 2: Production build
```bash
npm run build
```
Expected: `✔ done` with build output in `build/`.

### Task 3: Sync Android
```bash
npx cap sync android
```
Expected: exits 0 with "✔ Sync finished". Confirms the new web bundle is copied
into `android/app/src/main/assets/public/` and the AdMob plugin is registered.

## Verification Checklist

- [ ] `npm run check` exits 0 — no TypeScript errors
- [ ] `npm run build` exits 0 — no build errors
- [ ] `npx cap sync android` exits 0
- [ ] `android/app/src/main/AndroidManifest.xml` has `com.google.android.gms.ads.APPLICATION_ID`
- [ ] `capacitor.config.ts` has `AdMob.appIdAndroid`
- [ ] `src/lib/effects/admob.ts` exists
- [ ] `src/lib/stores/game.ts` exports `hintBalance`
- [ ] `HintButton.svelte` imports `hintBalance`, `isAdReady`, `requestAdHint`, `Capacitor`

## UAT Criteria (human device test — post-commit)

1. **Ad preload**: Open app on Android device — no crash, no console errors from AdMob
2. **Watch Ad visible**: During 30s cooldown with balance=0, ad sub-button appears
3. **Ad plays**: Tap "📺 Watch ad" — test ad video plays to completion
4. **Reward granted**: After ad completes, hint balance increments by 1
5. **Balance hint**: With balance > 0, tap `💡 Hint` — hint displays without starting cooldown
6. **Web hidden**: On PWA (browser), Watch Ad button is never visible

## ⚠ Manual Step Required (before production build)

Replace test IDs with real AdMob IDs before submitting to Google Play:
1. Create app at https://admob.google.com → get App ID
2. Create rewarded ad unit → get Ad Unit ID
3. Update `REWARD_AD_ID` in `src/lib/effects/admob.ts`
4. Update `android:value` in `AndroidManifest.xml`
5. Update `AdMob.appIdAndroid` in `capacitor.config.ts`
6. Set `isTesting: false` in `capacitor.config.ts`
