# Plan 11-04 — HintButton UI Update

## Goal
Update `src/lib/components/HintButton.svelte` to:
1. Use `hintBalance` credits first (bypasses cooldown)
2. Show "📺 Watch ad" / "No ad available" sub-button during cooldown on native builds
3. Never show Watch Ad on web (D-03)

## Current behaviour (unchanged)
- `💡 Hint` when ready, `⏱ Xs` during cooldown
- Organic hint: sets `hintCooldownEndsAt + 30s`

## New behaviour
- When `$hintBalance > 0`: hint button label stays `💡 Hint`, works with no cooldown penalty
- When `$hintBalance == 0` AND `cooldownRemaining > 0` AND `isNative`:
  - Show sub-button below cooldown timer
  - `isAdReady` → `📺 Watch ad` (enabled)
  - `!isAdReady` → `No ad available` (disabled)
- Sub-button never shown on web (`isNative = false`)

## Tasks

### Task 1: Update script block

Add imports:
```ts
import { hintBalance } from '../stores/game.js';
import { isAdReady, requestAdHint } from '../effects/admob.js';
import { Capacitor } from '@capacitor/core';
```

Add runtime constant (computed once — doesn't need reactivity):
```ts
const isNative = Capacitor.isNativePlatform();
```

Modify `hint` derived — compute even during cooldown if balance > 0:
```ts
const hint = $derived(
  (cooldownRemaining === 0 || $hintBalance > 0) ? getHint($unlockedElements) : null
);

const canHint = $derived(hint !== null && ($hintBalance > 0 || cooldownRemaining === 0));
```

Modify `useHint()` — use balance if available (no cooldown change):
```ts
function useHint() {
  if (!canHint || !hint) return;
  if ($hintBalance > 0) {
    hintBalance.update((n) => n - 1); // balance hint — no cooldown applied
  } else {
    hintCooldownEndsAt.set(Date.now() + COOLDOWN_MS); // organic hint
  }
  hintVisible = true;
}
```

### Task 2: Update template — add Watch Ad sub-button

Inside `.hint-wrapper`, after the `<button class="hint-btn">` block:
```svelte
{#if isNative && cooldownRemaining > 0 && $hintBalance === 0}
  <button
    class="ad-btn"
    disabled={!$isAdReady}
    onclick={requestAdHint}
    aria-label={$isAdReady ? 'Watch ad for hint' : 'No ad available'}
  >
    {$isAdReady ? '📺 Watch ad' : 'No ad available'}
  </button>
{/if}
```

## Verification
- Balance hint: `$hintBalance > 0` → hint fires, balance decremented, cooldown unchanged
- Organic hint: `$hintBalance == 0`, `cooldownRemaining == 0` → hint fires, cooldown set to +30s
- Watch Ad button: visible only during cooldown + native + balance == 0
- Disabled state: `$isAdReady == false` → button shows "No ad available", non-interactive
- Web: ad sub-button never renders (`isNative = false`)
