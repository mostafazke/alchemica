Fix the hard Android blocker that silently cancels purchases, then install the
RevenueCat Capacitor plugin.

3D-Secure payment verification will have their purchase silently cancelled when they
return to Alchemica. This is a silent data-loss bug (user charged, entitlement not
granted) that cannot be fixed post-ship. It must be resolved before any other IAP
work executes.

- package.json + node_modules: @revenuecat/purchases-capacitor@13.0.1
- android/ platform: synced with new plugin native code

<task type="auto">
  <name>Task 2: Fix AndroidManifest.xml launchMode singleTask → singleTop</name>
  <files>android/app/src/main/AndroidManifest.xml</files>
  <action>
    In android/app/src/main/AndroidManifest.xml, change the MainActivity launchMode
    attribute from "singleTask" to "singleTop".

    Find line:
        android:launchMode="singleTask"

    Replace with:
        android:launchMode="singleTop"

    Context: The activity block looks like this (change only the launchMode attribute,
    leave all other attributes unchanged):

        <activity
            android:configChanges="orientation|keyboardHidden|keyboard|screenSize|locale|smallestScreenSize|screenLayout|uiMode|navigation|density"
            android:name=".MainActivity"
            android:label="@string/title_activity_main"
            android:theme="@style/AppTheme.NoActionBarLaunch"
            android:launchMode="singleTop"               <!-- was "singleTask" -->
            android:screenOrientation="sensorLandscape"
            android:exported="true">

    Rationale (per 12-RESEARCH.md): RevenueCat's billing flow redirects to a banking
    app for 3D-Secure. When the user returns, Android re-creates the activity stack.
    With "singleTask", the new activity intent destroys the purchase flow. "singleTop"
    prevents duplicate instances (same Capacitor behavior) while allowing the
    purchase callback to complete.
  </action>
  <verify>
    grep -c 'launchMode="singleTop"' android/app/src/main/AndroidManifest.xml
    # Expected output: 1
    grep -c 'launchMode="singleTask"' android/app/src/main/AndroidManifest.xml
    # Expected output: 0
  </verify>
  <done>AndroidManifest.xml contains launchMode="singleTop" and does not contain "singleTask".</done>
</task>
