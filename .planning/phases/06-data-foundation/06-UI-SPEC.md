## Copywriting Contract

Phase 6 has one copywriting change: the discovery counter label in TopBar.

| Element | Current Copy | New Copy (Phase 6) | Requirement |
|---------|-------------|---------------------|-------------|
| Discovery counter stat | `🔬 {count}/{total}` | `{count}/{total} discovered` | PROG-01, D-09 |

Rules:
- Remove the `🔬` emoji — per D-09.
- Append the word `discovered` after the fraction — per D-09.
- Total remains `Object.keys(ELEMENTS).length` — dynamic, not hardcoded `61` — per D-10.
- No new derived store for the count — `$unlockedElements.size` used directly in the template — per D-11.

No empty states, error states, or destructive confirmations are introduced in Phase 6. The reset button and its hover behavior remain unchanged.

## Component Change Specification

### TopBar.svelte — Discovery Counter

**File:** `src/lib/components/TopBar.svelte`

**Change type:** Text-only — no layout, no new classes, no new styles.

**Before (line 10):**
```svelte
<span class="stat">🔬 {$unlockedElements.size}/{Object.keys(ELEMENTS).length}</span>
```

**After:**
```svelte
<span class="stat">{$unlockedElements.size}/{Object.keys(ELEMENTS).length} discovered</span>
```

**Style impact:** None. The `.stat` CSS class is unchanged. Color remains `#8ab4d4`. Font remains `Space Mono` at 12px, weight 400.

**No new CSS rules** are introduced in Phase 6 for TopBar. The Phase 8 pulse animation (`@keyframes` + `.pulse` modifier on this span) is deferred — per D-12.
